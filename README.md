# Sentosa Sans

A compact type family for English, Vietnamese and Thai, with Regular (400) and Bold (700). The Latin character set also supports everyday Malay, Indonesian and Filipino text.

This repository hosts the Sentosa Sans website, interactive specimens, and downloadable fonts. It is a self-contained static site: no package installation or build service is required.

## Download

[Sentosa Sans v0.5.1 — TTF + WOFF2](downloads/SentosaSans-v0.5.1.zip)

The package contains both weights, web CSS, documentation, credits, and licence notices.

## Website

[Visit the Sentosa Sans website](https://mlikeason.github.io/sentosa-sans/)

GitHub Pages serves the `main` branch from the repository root. All assets use relative paths, including the font download.
