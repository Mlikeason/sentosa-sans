# Sentosa Sans 0.5.1

One family for English, Vietnamese and Thai, in two real weights: Regular (400) and Bold (700). The Latin coverage also supports ordinary Malay, Indonesian and Filipino text. Each font covers these languages in one file.

## Use

- Install the TTF files for desktop and native-app workflows.
- Keep `fonts.css` next to the `woff2` folder for the web. Load the stylesheet and set `font-family: 'Sentosa Sans', sans-serif`.
- Use weights 400 or 700. Set `font-synthesis: none` to avoid synthetic styles.
- `ss01` selects commerce figures and punctuation; `tnum` and `pnum` select tabular and proportional figures. `ss02` provides readable identifier forms; `zero` enables a slashed zero.
- Currency order, separators, decimal precision and localized amounts belong to your application's locale formatting.
